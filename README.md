MySQL Assignment 2 – Querying Data
This project focuses on querying and analyzing employee data using MySQL.

Topics Covered

- DISTINCT
- Aliases
- WHERE conditions
- ORDER BY
- LIMIT
- Aggregate Functions
- GROUP BY
- HAVING
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN

Database
The project uses an employee database with the following tables:

- employees
- departments
- location

Description
The assignment demonstrates how SQL queries can be used to filter, sort, summarize, group, and combine data from multiple tables.
It also includes practical examples of updating missing employee information and using different types of JOINs.

Tools Used

- MySQL
- MySQL Workbench
